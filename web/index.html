What it does

Built for daily ops, not dashboard clutter.

Focused tools for the tasks staff teams handle every shift.

Audit-ready logging

Track moderation actions, message edits, member changes, and command usage in a clean staff-readable format.

Private tickets

Button-based support panel creates private channels on demand, keeping staff workflows organized.

Moderation tools

Purge, kick, ban, slowmode, lock, unlock, and announce with Discord-native permission enforcement.

Economy system

Daily streaks, work shifts, coinflip, slots, blackjack, gambling, robberies, a full item shop, and leaderboard.

Postgres persistence

Guild config, command logs, economy balances, and user inventory are all database-backed and migration-managed.

Production-ready

Built with health checks, graceful shutdown, API-first status reporting, and a public status page.
