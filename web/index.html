What it does

Built for daily ops, not dashboard clutter.

Focused tools for the tasks staff teams handle every shift.

Audit-ready logging

Track moderation actions, message edits, member changes, and command usage in a clean staff-readable format.

Private tickets

A simple button-based support panel creates private channels on demand, keeping staff workflows organized and permission-safe.

Moderation tools

Purge, kick, ban, and announce commands with Discord-native permission enforcement and optional reason logging.

Economy system

Daily streaks, work shifts, coinflips, slot machine, robberies, a full item shop, and a live leaderboard.

Postgres persistence

Guild config, command logs, economy balances, and user inventory are all database-backed and migration-managed.

Production-ready

Deployed on Fly.io with health checks, graceful shutdown, API-first status reporting, and a public status page.
