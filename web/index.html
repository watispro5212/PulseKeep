What it handles

Everything a staff team needs without a messy dashboard.

PulseKeep focuses on practical moderation and community operations that Discord servers repeat every day.

Audit-ready logging

Track moderation events, edited messages, channel updates, role changes, and command usage in a format staff can scan quickly.

Private tickets

Use category-level permission patterns for cleaner support channels that are easier to reason about and safer to maintain.

Moderation tools

Run purge, kick, ban, announce, user lookup, avatar, and server information commands with Discord permission checks.

Operational analytics

Expose lightweight stats and health endpoints for the website, deploy checks, uptime tools, and future dashboards.

Postgres persistence

Keep guild settings, command logs, and economy balances in a Drizzle-managed Postgres schema.

Deploy-friendly runtime

Designed for one always-on Fly.io machine with graceful shutdown, API-only startup support, and Netlify static hosting.

Deployment path

Clear setup for Fly.io, Netlify, and Postgres.

PulseKeep can run its API even before every secret is configured, which makes first deploys easier to debug. Add secrets when you are ready for the full Discord bot.

  1. Deploy the Go service to Fly.io Use `fly deploy`, then confirm `/health` returns status and uptime.
  2. Set production secrets Add `DISCORD_TOKEN`, `DATABASE_URL`, and optionally `ALLOWED_ORIGIN` for the Netlify domain.
  3. Publish the static site on Netlify Set the publish directory to `web`; the site fetches live stats from the Fly app.
