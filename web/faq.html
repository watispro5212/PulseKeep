FAQ

Frequently Asked Questions

Quick answers to the most common questions about PulseKeep.

How do I add PulseKeep to my server?
Click the Invite button in the top-right of any page, or use this direct link. You need Manage Server permissions to add bots. All commands are slash commands — start typing / in any channel after adding.
How do I set up moderation logging?
Use /configure modlogs on to enable logging, then /configure log_channel to pick which channel logs go to. The bot will log bans, kicks, warns, mutes, message edits/deletes, and member joins/leaves.
How do I set up the ticket system?
First create a category channel for tickets to live in. Then run /configure tickets on and /configure ticket_category to pick that category. Finally, use /ticketpanel in any channel to post the create-ticket button. Users click it to open a private ticket.
How do I enable auto-moderation?
Run /configure automod on to enable the system. Then toggle individual filters: /configure automod_spam on, automod_mentions, automod_caps, automod_links, and automod_words. You can set thresholds, actions (warn/delete/timeout), exempt roles, and allowed domains — all under /configure automod_* subcommands.
Why doesn't the bot respond to my commands?
Make sure you're typing a slash command (/) — PulseKeep has no prefix commands. If slash commands don't show up, re-invite the bot with the applications.commands scope. If the bot is offline, check the Status page for live service health.
What are Pulses and how do I earn them?
Pulses are the economy currency. Earn them via /daily, /weekly, /work, /fish, /mine, /search, /gamble, /slots, /blackjack, and /vote. Buy items from the /shop and check your balance with /balance. Use /cooldowns to see when your next claim is ready.
Can I reset my economy data?
There is no self-service reset. Contact the bot owner in the support server to request a data reset. Server admins can view warnings and history with /history.
How do I report a bug or suggest a feature?
Join the support server on Discord, or open an issue on GitHub.
Is PulseKeep open source?
Yes! PulseKeep is open source under the MIT License. The source code is available on GitHub. Contributions, forks, and self-hosting are welcome per the license.
What permissions does PulseKeep need?
The invite uses Administrator for full functionality. If you prefer a restricted setup, the bot needs: Read Messages, Send Messages, Embed Links, Manage Messages, Kick/Ban Members, Moderate Members (timeouts), Manage Roles, Manage Channels, Move Members, Read Message History, and Attach Files. Without these, some commands may fail.
