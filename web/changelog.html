Changelog

Every PulseKeep release, from the latest patch to the very first deploy.

v6.0.0

Economy audit, frontend rebuild, graceful degradation

May 30, 2026
  • Gamble EV fixed — 5% house edge (was losing on rolls ≤40, now losing only on ≤39; 40+ pushes)
  • Rob shield fixed — fine no longer transfers money to the target; shield now purely blocks the robbery
  • Sell fixed — refund no longer added to the Earned stat
  • Inventory race fixed — replaced RLock with full Lock in the Inventory() method
  • Blackjack rewritten — button-based Hit/Stand interaction with 90-second timeout cleanup
  • Moderation guards — kick and ban reject self-targeting; announce rejects @everyone without MentionEveryone permission
  • API OAuth — random state parameter stored in cookie, validated on callback for CSRF protection
  • API guild config — ManageGuild permission verified via Discord API before read/write
  • Health check — always returns 200 OK (database status reported in body only)
  • Graceful degradation — log.Fatalf replaced with log.Printf in database, migration, and bot init; web server stays running in degraded mode
  • FlushAll — saves all economy data on graceful shutdown
  • Inventory UPSERT — replaced DELETE+INSERT with ON CONFLICT DO UPDATE to eliminate data-loss window
  • Website completely rebuilt — all HTML pages rewritten, style.css modernized, status page with live metrics
  • Dockerfile updated — Go 1.26, Alpine 3.21, COPY web /web
  • fly.toml cleaned — removed duplicate sections from bad merge
