Changelog

Release history and version notes for PulseKeep.

Version History

Version Date Changes
v5.5 May 2026
  • Fixed CRITICAL: /leaderboard command now routes to its handler instead of falling through to help menu
  • Fixed HIGH: /lock no longer wipes all existing channel permission overwrites — preserves role and member overrides
  • Fixed HIGH: /unlock no longer clears all permission overwrites — only removes @everyone SendMessages deny
  • Fixed: Inconsistent switch-case indentation across all command handlers
  • Added /about command showing PulseKeep version, tech stack, and project links
  • Added /about to interactive help menu and commands reference
  • Rewrote server.md with 7-section layout, economy guide, lock/unlock workflow, FAQ, and launch checklists
  • Heavily redesigned team page with 6 team cards, 8-item tech stack grid, open source section, and contribution callout
  • Updated status page to include rotating top.gg-compliant presence
  • Updated commands.html with /about and improved economy descriptions
v5.4 May 2026
  • Added /gamble command (1-100 dice roll, up to 10x payout)
  • Added /fish mini-game with 13 fish types across rarities (requires Fishing Rod)
  • Added /mine mini-game with 13 ore types across rarities (requires Iron Pickaxe)
  • Added /sell command for 60% item refunds
  • Added /use command for consumable items (Shield Token, Health Potion)
  • Shield Token now actively protects targets from robbery
  • Passive interest system: 0.1% balance growth every 6 hours
  • Added /unban command (DeleteBan API)
  • Added /slowmode command (RateLimitPerUser channel edit)
  • Added /nick command (member nickname via UpdateMember)
  • Added /timeout command (CommunicationDisabledUntil)
  • Added /lock and /unlock channel permission commands
  • Updated /profile to show gambling, fishing, mining stats
  • Shop now includes Fishing Rod, Iron Pickaxe, Lottery Ticket, Health Potion
  • 10 new shop items across economy and gameplay categories
v5.3 May 2026
  • Added /poll command with multi-option voting and reactions
  • Added /role command with automatic add/remove toggle
  • Implemented /purge, /kick, /ban moderation commands
  • Improved serverinfo, userinfo, avatar embeds with richer data
  • Overhauled /announce embed with author avatar and name
  • Cleaned up help menu by removing redundant Overview button
  • Added changelog page to website
  • Fixed tickets panel footer message
v5.2 May 2026
  • Added 5 new economy commands: /rob, /shop, /buy, /inventory, /slots
  • Shop with 5 purchasable items
  • Slots machine with 7 symbols and up to 10x payout
  • Real-time bot stats tracking via atomic counters
  • /stats and /health endpoints return live data
  • 7 new unit tests for economy features
  • Removed support.html from website
v5.1 May 2026
  • Fixed ticket button to create private channels with permission overwrites
  • Added duplicate ticket detection
  • Added Close Ticket button with 5-second channel deletion
  • Removed /menu command
  • Improved /ping, /stats, /help response embeds
v5.0 May 2026
  • Complete rewrite in Go using disgo library
  • PostgreSQL persistence via Neon
  • Economy system with balance, daily, work, pay, coinflip, leaderboard
  • Interactive help menu with category dropdown
  • Ticket panel with open/close flow
  • Static website with glassmorphism design
  • Real-time status page with auto-refresh
