Release history.

Every update to PulseKeep, documented.

v7.0.0 — TypeScript Rewrite

June 2025
  • Complete rewrite from Go to TypeScript
  • 30+ slash commands across Economy, Moderation, Tickets, and Utility
  • New dashboard with per-server toggle controls
  • Live status page with real-time metrics
  • Guild toggle enforcement (economy/tickets on/off)
  • Command logging to database
  • Auto-moderation engine (spam, links, caps, keywords)
  • Button-based ticket system with add/remove/close/rename

v6.2.0 — Redesign & QoL

May 2026
  • Dashboard rebuilt with per-server sidebar navigation
  • New premium card accents across all pages
  • Economy odds buffed (gamble 55% win rate)
  • 22 work jobs with flavor text
  • New shop items: Lucky Clover, XP Boost, Treasure Map
  • Daily/weekly streak milestones
  • Added /warn, /warnings, /clearwarns, /move, /vckick
  • Added /ticket add/remove/close/rename subcommands
  • Added /servericon, /roleinfo, /channelinfo, /invite
