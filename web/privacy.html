Privacy Policy

Last updated: June 2026

1. Data We Collect

PulseKeep collects the following data when you use the bot or dashboard:

  • Discord IDs — User IDs, guild IDs, channel IDs, role IDs for command execution and configuration.
  • Command usage — Command names, timestamps, and guild/user IDs for analytics and audit logging.
  • Economy data — Balances, inventory items, transaction history, and streak information.
  • Moderation data — Warning records including moderator ID, user ID, reason, and timestamp.
  • Guild configuration — Toggle states, ticket category IDs, log channel IDs, and other settings.

2. How We Use Data

All collected data is used exclusively to provide bot functionality:

  • Execute commands and maintain economy state
  • Persist guild configuration across restarts
  • Track moderation actions for audit purposes
  • Display live statistics on the status page
  • Authenticate dashboard users via Discord OAuth2

3. Data Storage & Security

Data is stored in a PostgreSQL database hosted on Supabase with encrypted connections. We do not share, sell, or transmit your data to third parties. Dashboard authentication tokens are stored locally in your browser and never exposed to third parties.

4. Data Retention

Economy data and warnings are retained until you request deletion or remove the bot from your server. Command logs may be periodically pruned. Contact us to request data deletion.

5. Contact

For privacy concerns or data deletion requests, join our support server or contact the development team.
