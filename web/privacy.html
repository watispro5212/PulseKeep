Privacy Policy

Effective: May 30, 2026

Data Collected Data We Do NOT Collect Why We Store Data Data Retention Third-Party Access Data Deletion Requests

1. Data Collected

PulseKeep stores the following types of data in its PostgreSQL database:

  • Guild configuration - per-server settings such as command prefix, log channel ID, staff role ID, and welcome message preferences.
  • User economy data - wallet balances, bank balances, earned/spent totals, gambling statistics, and inventory items for users who interact with economy commands.
  • Command usage logs - command name, user ID, guild ID, channel ID, and timestamp for moderation and operational audit purposes.
  • OAuth session data - temporary session cookies and OAuth state tokens used during dashboard authentication.

2. Data We Do NOT Collect

  • Message content (PulseKeep does not read or log message content)
  • Voice data or screen-sharing content
  • IP addresses or network metadata
  • Personally identifying information beyond Discord user IDs

3. Why We Store Data

Data is stored strictly for operational purposes:

  • Guild configurations enable per-server customization
  • Economy data enables balance persistence, item ownership, and leaderboards
  • Command logs provide server staff with audit trails for moderation actions
  • OAuth sessions enable the web dashboard

4. Data Retention

Data is retained until the bot is removed from a guild or a user requests deletion. When PulseKeep leaves a guild, associated guild configuration and command logs are cleaned up. Economy data may be retained in aggregate form for leaderboard integrity.

5. Third-Party Access

PulseKeep does not sell or share user data with third parties. The following services are used for hosting:

  • Production hosting - runtime infrastructure for the bot and API.
  • Neon - PostgreSQL database hosting

6. Data Deletion Requests

To request deletion of your data, join the PulseKeep support server or contact the developer directly. Deletion requests are processed within 30 days.
