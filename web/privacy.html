Privacy Policy

Last updated: June 2026

1. Data We Collect

Here's what we collect when you use the bot:

  • Discord IDs — User IDs, guild IDs, channel IDs, and role IDs for command execution and persistent configuration.
  • Command usage — Command names, timestamps, and guild/user IDs for analytics, audit logging, and rate limiting.
  • Economy data — Balances, inventory items, transaction history, and daily streak information.
  • Moderation data — Warning records including moderator ID, user ID, reason, and timestamp.
  • Guild configuration — Toggle states, ticket category IDs, log channel IDs, and other server-specific settings.

2. How We Use Data

We only use this stuff to make the bot work:

  • Execute commands and maintain economy state across restarts
  • Persist guild configuration so settings survive bot reboots
  • Track moderation actions for audit and transparency purposes
  • Display live aggregate statistics on the public status page

3. Data Storage & Security

Stored in a Postgres database on Supabase with TLS encryption. We don't share or sell anything. Only the bot can touch the database — no public access.

4. Data Retention

Economy data and warnings are retained until you request deletion or remove the bot from your server. Command logs may be periodically pruned. To request full data deletion, contact us through our support server.

5. Contact

For privacy concerns or data deletion requests, join our support server or contact the development team directly on Discord.
