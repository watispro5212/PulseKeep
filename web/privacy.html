Privacy Policy

Last updated: May 2026

Information we collect

PulseKeep may store Discord user IDs, guild IDs, channel IDs, guild configuration, economy balances, cooldown timestamps, and command usage records needed to operate the bot.

PulseKeep does not sell user data. Message content is not stored for general logging unless a command explicitly needs the submitted text to complete the requested action.

How we use data

  • Provide moderation, ticketing, utility, analytics, and economy features.
  • Keep guild settings and command behavior consistent across restarts.
  • Display aggregate service statistics without exposing private server data.

Data security

Production data should be stored in Postgres with secrets managed through the hosting provider. Bot tokens, database URLs, and private credentials must never be committed to the repository.

Deletion requests

Server owners and users can request deletion of stored data through the configured support channel. Records tied to required abuse prevention or operational logs may be retained when necessary.

Contact

For questions about privacy or data handling, use the PulseKeep support link configured on the website.
