Tech stack

How PulseKeep is built

Go

Backend runtime for the bot, API server, command handlers, tickets, moderation tools, and database layer.

Disgo

Discord API library used for slash commands, event handling, components, and gateway interactions.

Cloudflare Worker

Public website gateway that serves pages and forwards API, auth, health, and stats requests without exposing the backend origin.

pgx

PostgreSQL driver for all database operations - guild config, economy, inventory, and command logging.
