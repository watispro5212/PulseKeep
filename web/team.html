Project team

Built for real Discord staff work.

PulseKeep is a solo-built, Go-powered Discord bot with a public website, live metrics, and review-ready documentation.

Owner & Developer

PulseKeep is built and maintained by watispro1. The entire Go backend, Discord integration, website, and deployment pipeline are managed as a single project.

Infrastructure

PostgreSQL via Neon for persistence, Fly.io for the Go backend, Netlify for the frontend site, with GitHub Actions for CI/CD and auto-deployment.

Support

Community support is available through the ticket panel in any server running PulseKeep. For direct inquiries, reach out to watispro1 on Discord.
