Project team

Built for real Discord staff work.

PulseKeep is a solo-built, Go-powered Discord bot with a public website, live metrics, and review-ready documentation. One developer, one vision, 40+ commands.

Owner & Developer

watispro1 is the sole developer behind PulseKeep. Every line of Go backend code, Discord integration, website page, deployment pipeline, and documentation file is written and maintained by one person. The bot went from concept to production in a single development cycle, using modern Go patterns and the disgo library for Discord interactions.

Backend & Data

Go powers the bot process — a single binary handling gateway events, slash commands, economy logic, ticket management, and REST API endpoints. PostgreSQL via Neon provides serverless persistence for balances, inventories, shop items, and transaction history. The bot starts instantly and maintains a persistent WebSocket connection to Discord's gateway.

Deployment & CI/CD

Fly.io hosts the Go binary as a globally distributed application with automatic TLS, health checks, and scale-to-zero for idle periods. Cloudflare Workers serves the static website with edge caching and the same-origin API proxy eliminates CORS issues. GitHub Actions runs tests, builds the binary, and auto-deploys both backend and frontend on every push to main.

Support & Community

Community support is handled through the built-in ticket panel in any server running PulseKeep. Staff teams use the /ticketpanel command to create a support entry point, and members open tickets with a single button click. For direct inquiries, reach out to watispro1 on Discord.

Support channels are private. Staff will never ask for your bot token.

Security & Compliance

PulseKeep follows Discord's bot best practices and top.gg review guidelines. The bot does not collect personal data, logs are limited to operational metrics, and all economy transactions are validated server-side. A SECURITY.md file is available in the repository for reporting vulnerabilities.
