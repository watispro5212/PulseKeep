PulseKeep Commands

A comprehensive list of all available slash commands for PulseKeep.

General

/ping — Check if PulseKeep is alive and responding.
/uptime — Display how long PulseKeep has been running.
/stats — View PulseKeep's current operational statistics.
/help — List all available PulseKeep commands.
/serverinfo — Show detailed information about the current server.
/userinfo [user] — View detailed information about a user.
/avatar [user] — Display a user's avatar in full resolution.

Economy

/balance [user] — Check your current PulseKeep balance.
/daily — Claim your daily Pulses reward.
/work — Work a shift to earn some Pulses.
/pay <recipient> <amount> — Send Pulses to another user.

Moderation

/kick <user> [reason] — Kick a member from the server.
/ban <user> [reason] — Ban a member from the server.
/purge <amount> — Bulk delete messages (1-100).
/setlog <channel> — Set the logging channel for the server.
