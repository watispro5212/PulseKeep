Slash command reference

All PulseKeep commands

A complete reference for server admins, staff teams, and Top.gg reviewers. Click any command to copy it.

Add to Discord Live status

Utility

/pingCheck whether PulseKeep is responding.
/uptimeShow how long the bot process has been online.
/statsView a live operational snapshot of the bot.
/helpOpen the interactive command browser inside Discord.
/serverinfoShow server metadata for the current guild.
/userinfo [user]Look up account details for yourself or another member.
/avatar [user]Display a user's avatar at full resolution.

Moderation

These commands require staff-level Discord permissions.
/purge <amount>Bulk delete messages in the current channel (1–100).
/kick <user> [reason]Remove a member from the server with an optional reason.
/ban <user> [reason]Ban a member from the server with an optional reason.
/announce <title> <message>Send a clean embedded announcement to the channel.

Tickets

/ticketpanelPost the interactive ticket panel for members to open support requests.

How tickets work

When a member clicks "Open Ticket" on the panel, PulseKeep creates a private channel that only the member and staff can see. Members can close their ticket with a button, and the channel is deleted automatically.

Economy

/balance [user]Check your Pulse balance or another user's balance.
/profile [user]View wallet, earned/spent totals, and daily streak.
/dailyClaim your daily Pulses reward (streak bonus included).
/workWork a shift to earn Pulses (45m cooldown).
/pay <user> <amount>Send Pulses to another member.
/rob <user>Attempt to steal Pulses from another member (40% success rate, 4h cooldown).
/coinflip <amount> <side>Wager Pulses on a heads-or-tails coinflip.
/slots <amount>Spin the slot machine — match 3 for up to 10x your wager.
/shopBrowse the PulseKeep item shop for purchasable items.
/buy <item>Purchase an item from the shop using item ID.
/inventoryView items you own.
/leaderboardShow the richest PulseKeep economy members.
