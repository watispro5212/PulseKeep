Slash command reference

PulseKeep commands

A practical command reference for Top.gg reviewers, server admins, and staff teams testing PulseKeep.

Add to Discord View status

General and utility

/pingCheck whether PulseKeep is responding.
/uptimeShow how long the current bot process has been online.
/statsView a live operational snapshot for the bot.
/helpOpen the interactive command browser inside Discord.
/menuOpen PulseKeep's category-based command menu.
/serverinfoShow server metadata for the current guild.
/userinfo [user]Look up account details for yourself or another member.
/avatar [user]Display a user's avatar in full resolution.

Moderation and logs

/purge <amount>Bulk delete messages in the current channel.
/kick <user> [reason]Kick a member with an optional moderation reason.
/ban <user> [reason]Ban a member with an optional moderation reason.
/announce <title> <message>Send a structured announcement embed.

Tickets

/ticketpanelPost the interactive ticket panel for member support requests.

Economy

/balance [user]Check a member's current PulseKeep balance.
/profile [user]View economy profile details for a member.
/dailyClaim a daily Pulses reward.
/workRun a work shift to earn Pulses.
/pay <recipient> <amount>Send Pulses to another member.
/coinflip <amount> <side>Wager Pulses on a heads-or-tails coinflip.
/leaderboardShow the richest PulseKeep economy members.
